# Levantamiento RQ

Plataforma distribuida para el levantamiento, análisis, edición,
revisión y aprobación de requerimientos con apoyo de inteligencia
artificial.

## Arquitectura prevista

- Frontend responsive independiente
- API Gateway / BFF
- Identity Service
- Project Service
- Source Service
- Document Service
- AI Analysis Service
- Workflow Service
- Operations Service

## Stack principal

- NestJS
- TypeScript
- Fastify
- TypeORM
- SQL Server / Azure SQL
- Passport, JWT y cookies seguras
- BullMQ y Redis
- RabbitMQ / Azure Service Bus
- MinIO / Azure Blob Storage
- OpenAI API
- Nx
- pnpm
- Docker Compose
