# Reglas de exportación

## Formatos previstos

- PDF como formato final inicial.
- DOCX editable en una fase posterior.
- JSON estructurado para integraciones y auditoría.

## Orden

La exportación conserva estrictamente las trece secciones de la plantilla
1.0.0 y su numeración.

## Formato visual

- Fuente: Arial, Aptos o fuente corporativa.
- Título principal: 16 puntos.
- Título de capítulo: 13 o 14 puntos.
- Subtítulo: 11 o 12 puntos.
- Texto: 10,5 u 11 puntos.
- Tablas: 9 o 10 puntos.
- Interlineado: 1,15.
- Márgenes: 2,5 cm.
- Títulos en negrita.
- Texto alineado a la izquierda.
- Encabezado con título, código y versión.
- Pie de página con número de página.
- Tablas con encabezado visible.
- Identidad visual corporativa sin recargar el documento.

## Diagramas

El sistema conservará una representación estructurada del flujo y podrá
renderizarla como Mermaid, BPMN simplificado o imagen aprobada.

## Información pendiente

Los marcadores `[PENDIENTE POR DEFINIR]` permanecen visibles mientras el
documento no haya completado la información requerida.
