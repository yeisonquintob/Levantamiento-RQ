# ADR-0009: Documento canónico de levantamiento

## Estado

Aceptada.

## Decisión

La plantilla `ESTÁNDAR COMPACTO PARA LEVANTAMIENTO DE REQUERIMIENTOS`,
versión 1.0.0, será la estructura canónica de salida.

El documento conservará exactamente trece secciones y su orden. No se
agregarán capítulos sin autorización y sin una nueva versión de plantilla.
