# Conocimiento ERP y análisis fit-gap

## Objetivo

Evaluar si una necesidad ya existe en Dynamics 365, puede resolverse por
configuración, está cubierta parcialmente, ya existe como personalización,
requiere extensión o integración, justifica una aplicación complementaria
o no cuenta con evidencia suficiente.

## No es una integración operacional

En esta etapa no se construirá conexión productiva, sincronización en
tiempo real, escritura de transacciones, OData, Business Events,
Dual-write ni automatización sobre Dynamics.

## Fuentes futuras

- Documentación funcional y manuales internos.
- Catálogo de módulos, procesos y parámetros.
- Workflows, tablas, campos y entidades de datos.
- Formularios, menús, reportes y roles.
- Extensiones, personalizaciones y metadatos controlados.
- Snapshots aprobados.

## Clasificaciones

| Código | Significado |
|---|---|
| ERP_STANDARD | Existe de forma estándar |
| ERP_CONFIGURABLE | Requiere configuración |
| ERP_EXISTING_CUSTOMIZATION | Ya existe como personalización |
| ERP_PARTIAL_FIT | Cubre una parte |
| ERP_EXTENSION_REQUIRED | Requiere extensión |
| ERP_INTEGRATION_REQUIRED | Requiere integración |
| EXTERNAL_APPLICATION_JUSTIFIED | Conviene aplicación complementaria |
| REPORTING_ANALYTICS | Se resuelve mediante reporte o analítica |
| INSUFFICIENT_EVIDENCE | No existe evidencia suficiente |
| OUT_OF_SCOPE | Fuera del alcance |

## Evidencia obligatoria

Toda conclusión incluirá sistema, módulo, proceso, capacidad, fuente,
snapshot o versión, cobertura, brechas, confianza, recomendación y
necesidad de revisión experta.
